# صفحة تحميل تطبيق دوايا | DAWAYA (صفحة مستقلة)

هذه صفحة هبوط تعريفية مستقلة تمامًا عن الموقع الرئيسي، مخصصة لتعريف المستخدم بتطبيق **دوايا (DAWAYA)** وتنزيل ملف **`DAWAYA.apk`** مباشرة على الأندرويد.

## طريقة النشر في دقيقتين (مجانًا وبعيد عن الموقع الرئيسي):

### الطريقة 1: GitHub Pages (الأسهل والأسرع)
1. أنشئ Repository جديد ومستقل على GitHub باسم مثلاً: `dawaya-download` (يكون **Public**).
2. ارفع الملفات الموجودة داخل هذا المجلد (`index.html` و `robots.txt` و `404.html`) مباشرة في الريبو الجديد.
3. من داخل الريبو ادخل على **Settings → Pages → Branch: main → Save**.
4. خلال دقيقة هيظهرلك رابطك المستقل:
   `https://mmo277.github.io/dawaya-download/`

### الطريقة 2: Cloudflare Pages (سريع جدًا وبرابط قصير)
1. افتح Cloudflare Pages → **Create application → Upload assets**.
2. اسحب ملف `dawaya-app-download-site.zip` مباشرة واضغط **Deploy**.
3. هيطلعلك رابط مستقل زي `https://dawaya-app.pages.dev`.

## عمل QR Code للطباعة أو العرض أمام اللجنة:
- حوّل رابط الصفحة المستقلة بتاعتك لـ QR Code، وأي شخص هيصوره بكاميرا الموبايل هتفتحله الصفحة التعريفية فورًا ويضغط **«تحميل تطبيق دوايا (DAWAYA.apk)»**.
- ولو عايز الكود يبدأ التحميل تلقائيًا أول ما الصفحة تفتح، أضف `?auto=1` في آخر الرابط (مثلاً: `https://dawaya-app.pages.dev/?auto=1`).
